# Cybersecurity Internship – TechBiz Security

This repository contains my work and practical learning activities completed during my **Cybersecurity Internship at TechBiz Security**. The internship focuses on two major areas: **Security Operations Center (SOC) Analysis** and **Ethical Hacking**.

## 🔐 SOC Analyst

The SOC Analyst section contains assignments and practical exercises related to defensive cybersecurity, including:

* SOC fundamentals and responsibilities
* CIA Triad and security concepts
* Threat, vulnerability, and risk analysis
* SOC L1, L2, and L3 analyst responsibilities
* Blue Team concepts
* Security monitoring and alert triage
* Threat detection and incident response
* SIEM fundamentals and log analysis
* Phishing analysis
* Network security monitoring
* Security incident reporting and documentation

The assignments are documented through reports explaining the concepts, analysis, findings, and practical learning outcomes.

## 🛡️ Ethical Hacking

The Ethical Hacking section focuses on understanding offensive security techniques and penetration-testing methodologies in authorized lab environments.

It includes:

* Ethical hacking fundamentals
* Reconnaissance and information gathering
* Scanning and enumeration
* Vulnerability identification
* Web application security
* Network security
* Exploitation concepts
* Post-exploitation concepts
* Security assessment and reporting
* Hands-on cybersecurity labs

Practical exercises are supported by **TryHackMe rooms**, where I document the rooms completed, concepts learned, tools used, methodology, and key takeaways.

## 🧪 TryHackMe

A dedicated section is included for my **TryHackMe learning journey**, containing documentation for completed rooms related to SOC analysis, networking, Linux, Windows, web security, reconnaissance, and ethical hacking.

Each room's documentation may include:

* Room name and objective
* Topics covered
* Tools/commands used
* Methodology
* Key findings
* Screenshots where appropriate
* Skills learned
* Final takeaways

TryHackMe's current SOC Level 1 path focuses on practical SOC skills such as alert triage, SIEM, phishing analysis, network monitoring, Windows/Linux security monitoring, threat intelligence, and incident investigation.

## 🎯 Objective

The main objective of this internship is to develop practical cybersecurity skills by combining **theoretical knowledge, security analysis, hands-on labs, TryHackMe exercises, technical reporting, and documentation**.

This repository serves as a portfolio of my cybersecurity learning journey and demonstrates my growing knowledge of both **defensive security (Blue Team/SOC)** and **offensive security (Ethical Hacking)**.

> **Note:** All security testing and exploitation activities documented in this repository are performed only in authorized educational environments and cybersecurity labs.
