# Cybersecurity Internship – TechBiz Security

This repository contains my work and practical learning activities completed during my **Cybersecurity Internship at TechBiz Security**. The internship focuses on two major area:**Ethical Hacking**.


## 🛡️ Ethical Hacking

The Ethical Hacking section focuses on understanding offensive security techniques and penetration-testing methodologies in authorized lab environments.

It includes:

* Ethical hacking fundamentals
* Reconnaissance and information gathering
* Scanning and enumeration
* Vulnerability identification
* Web application security
* Network security
* Exploitation concepts
* Post-exploitation concepts
* Security assessment and reporting
* Hands-on cybersecurity labs

Practical exercises are supported by **TryHackMe rooms**, where I document the rooms completed, concepts learned, tools used, methodology, and key takeaways.



## 🎯 Objective

The main objective of this internship is to develop practical cybersecurity skills by combining **theoretical knowledge, security analysis, hands-on labs, TryHackMe exercises, technical reporting, and documentation**.

This repository serves as a portfolio of my cybersecurity learning journey and demonstrates my growing knowledge of **offensive security (Ethical Hacking)**.

> **Note:** All security testing and exploitation activities documented in this repository are performed only in authorized educational environments and cybersecurity labs.
